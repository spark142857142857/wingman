# Wingman

Lightweight Windows terminal MVP (Tauri + xterm.js).

## Features
- PowerShell / cmd switching
- Linux Familiar mappings: `ls`, `ll`, `pwd`, `clear`, `cat`, `rm`, `mv`, `cp`
- Status bar: shell / compat / cwd
- Ctrl+Shift+C / Ctrl+Shift+V copy-paste helpers

## Run
```powershell
cd D:\Agent프로젝트\wingman
npm install
npm run tauri dev
```

## Notes
- No AI features in this MVP
- Demo-oriented UI with acrylic-like glass styling
